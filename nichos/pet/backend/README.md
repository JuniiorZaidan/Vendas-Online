# Backend da loja pet

Node.js 24 com módulos nativos HTTP e SQLite, sem dependências npm. Execute `npm start` a partir de `nichos/pet` para servir frontend e API juntos.

Consulte [a documentação do projeto](../README.md) para endpoints, variáveis, persistência, testes e limitações comerciais. O modo atual registra apenas pedidos demonstrativos; não recebe pagamentos.
