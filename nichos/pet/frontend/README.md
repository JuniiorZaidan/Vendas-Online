# Frontend e mídia da loja pet

HTML, CSS e JavaScript com 34 ilustrações próprias em `assets/produtos.png`. O build lê `../backend/catalog.json`, produz `catalog.js`, páginas individuais e arquivos estáticos em `dist/`.

Execute `npm run build` em `nichos/pet`. Para usar a API de pedidos, inicie `npm start` no mesmo diretório. Hospedagem estática mostra a vitrine, mas não registra pedidos.
